# AegisFlow

> Autonomous Work Execution Network

AegisFlow turns a vague goal into a verified, continuously monitored workflow — planning, delegating, executing, validating, recovering from failures, and reporting results without requiring the user to remain in the loop.

## One-line pitch

AegisFlow is an autonomous multi-agent execution system that plans, delegates, executes, verifies, heals, and reports on complex workflows asynchronously.

## Current status

This repository is a scaffold. The technology stack and agent contracts will be decided in the next daily task.

## Required environment

See `.env.example` for the variables needed to run the project.

## Local development

1. Copy `.env.example` to `.env` and fill in the values.
2. Start the backing services: `docker compose up -d`
3. Install dependencies and run the chosen app stack (to be added).
